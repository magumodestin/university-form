# Student Registration Form

A responsive student registration form built with HTML, CSS and JavaScript. It validates every field before submission and gives clear visual feedback when something is missing or wrong.

## Features

- Form validation on all fields (names, date of birth, ID/passport, email, phone, province, language, faculty, matric year, pass type)
- Red, shaking error messages for empty or invalid inputs
- Extra text input appears when "Other" is selected for gender or race
- Phone and matric year fields accept digits only
- Responsive layout for phones, tablets and desktops
- Success message and form reset after a valid submission

## Technologies

- HTML5
- CSS3 (Flexbox-friendly layout, media queries, animations)
- JavaScript (vanilla)

## Project Structure

```
├── home.html   # Form structure
├── home.css    # Styling and responsive design
└── home.js     # Validation logic
```

## How to Run

1. Download or clone this repository.
2. Open `home.html` in your browser.
